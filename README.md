
# AKAsheet: The Professional AI Rhyme Book & Studio Master Blueprint

**AKAsheet (BA)** is a high-end, universal workstation for musicians, rappers, and lyricists. It is designed to transform the chaotic process of writing a concept album into a structured, AI-assisted workflow. It assists the artist's writing process; it is not a full-song generator.

---

## 1. Core Philosophy & Problem Solved
**The Problem**: Artists struggle with "Creative Block" and "Thematic Drift."
**The Solution**: A workstation that learns the album's DNA (The 5 Questions) to ensure every bar generated fits the project perfectly.

---

## 2. Monetization & "The Toolbox Model"
The app uses a tiered subscription model centered around **Connectivity** and **AI Capacity (Ink)**.

### Current tiers
- **Visitor**: Limited cloud catalog plus 250 signup Ink and 150 monthly residency Ink, capped at 400.
- **Studio Pro**: Cloud workflow, expanded catalog, and monthly residency Ink.

The source-backed current economy is documented in [Monetization](./docs/MONETIZATION.md) and [Stripe setup](./docs/STRIPE_SETUP.md).

### The Ink Economy (Platform Access)
Ink represents the value of the studio's proprietary prompt architecture and workflow logic.
- **Generate Next Line**: 15 Ink.
- **Song Draft**: 2 Ink per bar.
- **Improve My Style**: 35 Ink.

### Power User Feature: BYO-API
- **Studio API Bypass**: Pro users can connect their own Google AI Studio key.
- **Platform Fee**: Users are still charged Ink even when using their own API key, covering the workstation's intellectual property and logic.

## 3. User Journey & Universal Accessibility

### A. Mobile Installation (Universal PWA)
Users can "Add to Home Screen" on iPhone/Android for a native full-screen experience.

### B. The Dashboard (The Vinyl & Cassette Collection)
- **The Scene**: Signed-in home for the friends feed, Your Booth, explainable Discover, public challenges, First Drops, and transparent Emerging momentum.
- **The Vault**: Full albums, loose tracks, Collab Sheets, the bar-by-bar workstation, Creative DNA, search, and versioned non-destructive backup/restore.
- **Public Music Home**: A free public identity for artists, creators, and Music Fans, with chosen labels, sound/taste, support relationships, and an owned or purchased featured track.
- **Direct-to-Fan Music**: First Drops let creators sell buy-once in-app streams. Listener Insights restores historical starts and sales while keeping them distinct from newly verified 80% listening, repeats, completion, sources, and conversion.

## 4. Technical Stack & Security
- **Next.js 15 / React / Tailwind**: High-performance UI.
- **Firebase Firestore**: Secure, account-based cloud storage (Pro Tier).
- **Firebase Storage + server tickets**: Private masters and selected 30-second profile excerpts stream through entitlement-aware APIs.
- **Stripe Connect**: First Drop checkout, tiered platform fees, creator payouts, held-sale handling, and detailed Earnings records.
- **Gemini 2.5 Flash**: Efficient, low-cost AI reasoning.
- **Roadmap**: Transitioning to **Google Antigravity** for long-term AI development.
