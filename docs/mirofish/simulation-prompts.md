# MiroFish — Simulation prompts (02 / Simulation Requirement)

**Upload [reality-seed.md](./reality-seed.md) once.** After GraphRAG finishes (~7–10 min), reuse the same graph — paste a different prompt below for each run.

Do **not** output fake conversion percentages. Rank upgrade intent **low / medium / high** per persona.

---

## Run 1 — Market positioning A (Catalog brain)

```
AKAsheet has just launched with MARKET A positioning: "AKAsheet is your album brain — Pro is for catalog workflow (DNA vault saves, Performance Mode, DNA Drop links)."

Simulate 30 days of conversation on Twitter-like and Reddit-like platforms among Marcus (indie album rapper), Priya (ghostwriter), Jaylen (hobbyist), Dre (Suno producer), and Tasha (trial-maximizer).

Fixed pricing: free (250 signup Ink + 150/mo, 1 album, 2 tracks, 2-day Pro feature preview). Pro $7.77/mo or $53.28/yr.

Inject events: (1) user hits 4-track limit, (2) DNA extraction complete but cannot save on free, (3) threads "AKAsheet vs Suno vs ChatGPT."

Who adopts immediately and why? Who hesitates — top 5 objections? Rank conversion hypotheses 1–8 per persona (credible vs unfair). Recommended hero headline for akasheet.com. Is word-of-mouth positive or skeptical?
```

---

## Run 2 — Market positioning B (Ink-first)

```
Same product and live pricing as Run 1, but MARKET B positioning only: "Everything works on Ink — Pro unlocks scale when caps and saves block you. Lead with Ink math (~104 Ink per Studio Draft, 250 signup + 150/mo, 400 cap)."

Same personas, platforms, and injected events as Run 1.

Report: "free too generous" narrative, ink-anxiety backlash, which headline works for Jaylen vs Marcus. Rank hypotheses 1–8. Compare upgrade intent to Market A if available.
```

## Run 3 — Pricing A (live stack)

```
Simulate free-to-Pro journeys for PRICING SCENARIO A (live): 2-day Pro feature preview, 2 free tracks, 150/mo residency (400 cap), Pro $7.77/mo or $53.28/yr.

Personas: Tasha (trial-maximizer), Jaylen ($10/mo budget), Marcus (yearly saver), Dre (ink-pack-only), Renee (downgraded).

Timeline: day 0 signup → day 1–2 heavy AI → day 3 trial ends at DNA save paywall → day 7 monthly ink grant → day 14 pricing page monthly vs yearly debate.

Stated upgrade intent by persona. Backlash risk (cheap price / trial scam). Monthly vs yearly preference. Top 3 pricing-page copy changes.
```

## Run 4 — Pricing B (hypothetical)

```
Simulate PRICING SCENARIO B (hypothetical, not live): NO Pro trial, 2 free tracks, 75/mo residency (350 cap), same Pro prices, yearly plan default on pricing page.

Same personas; day 1 block on 3rd track instead of day 3 trial expiry.

Does early track cap beat trial-end vault save for pay intent — or trigger "demo scam" backlash? Who hates 2-track cap most? Ship B for 90 days or keep A?
```

## Run 5 — Pick a winner (recommended after Runs 1–4)

Given all scenarios in the Reality Seed (Market A, Market B, Pricing A live, Pricing B hypothetical), which combined GTM package for akasheet.com's first 90 days minimizes trust backlash and maximizes stated Pro upgrade intent among indie album rappers vs hobbyists?

Recommend: positioning + trial policy + free track count + pricing page default (monthly vs yearly). Rank conversion hypotheses 1–8. Top 5 risks and mitigations.
