## Week 1–2 checklist (~5 hrs/week, $0 ads)

### Sunday batch (one session)

- [ ] **Record 4 clips** (phone, 9:16, dark UI, real finger taps):
  1. **Hook A** — “POV: same 4 bars for 3 weeks” → Generate Next Line
  2. **Hook B** — “Your notes app isn’t a rhyme book” → paste mess → Smart Structure
  3. **Hook C** — Rhyme Pulse on one bar (10s magic moment)
  4. **Hook D** — Add to Home Screen (PWA) — [MOBILE_STORE_GUIDE.md](./MOBILE_STORE_GUIDE.md) Phase 1
- [ ] **CapCut** (1.5 hr): trim 15–22s each, auto-captions, end card: “Free demo — link in bio”
- [ ] **Post schedule:** Mon / Wed / Fri / Sun → TikTok + cross-post Instagram Reels
- [ ] **Accounts:** `@Bar4BarStudio` (or your handle) — same name on TikTok, IG, YouTube
- [ ] **Track** in spreadsheet: views, profile clicks, signups (Admin Growth Metrics weekly)

### 20-second ad structure (every video)

| Sec | Visual | Text overlay |
|-----|--------|----------------|
| 0–2 | Pain | “Stuck on the next bar?” |
| 2–8 | Paste lyrics | “Paste your verse…” |

## Week 3–4 — Spark Ads ($5–10/day)

**Start only when** one organic post beats your average (≈2× views or more profile visits).

| Setting | Value |
|---------|--------|
| Platform | TikTok Ads → **Spark Ads** on winning organic post |
| Budget | $5/day × 14 days (~$70); cap month at $150–300 |
| Audience | Interests: songwriting, rap, music production, independent artist · 18–34 · US |
| Promote URL | `https://bar4bar.ink/login?mode=signup&ref=tiktok` |
| Creative | Boost the **same** organic video — do not shoot new ads yet |

### Weekly review

- [ ] Admin → **Growth Metrics** — signups last 7d, activation %, checkout completions
- [ ] TikTok Ads — cost per result; pause if signup CPA > ~$25 for 5+ days
- [ ] Note winning hook in Admin marketing notes (ad spend + notes fields)
- [ ] Optional: duplicate winner to Instagram Reels ad if TikTok CPA is acceptable

## Hook library (rotate)

**Cold traffic (start here):**

- POV: you’ve had the same 4 bars for 3 weeks
- Stop asking ChatGPT for a whole song
- Your notes app isn’t a rhyme book
- I paste my mess → it becomes verse / hook / verse

**Objection:**

- Web studio — works on phone, no App Store download (show PWA add-to-home)

## What not to do yet

- Broad Meta “brand awareness” campaigns
- Google Search ads
- Native App Store launch (see [APP_STORE_ROADMAP.md](./APP_STORE_ROADMAP.md) — after web signups work)
